# فرتاش — آموزشگاه آنلاین زبان

وب‌سایت آموزش زبان با Next.js 15، React 19 و Tailwind CSS (راست‌به‌چپ، فونت وزیرمتن).

## اجرا

```bash
npm install
npm run dev     # http://localhost:3000
npm run build && npm start
```

## صفحات

| مسیر | توضیح |
| --- | --- |
| `/` | صفحه‌ی اصلی: جمله‌نامه‌ی تعاملی، روش کار و یک هفته‌ی نمونه، زبان‌ها، اساتید، تعرفه‌ها، سوالات متداول |
| `/design-system` | مرجع زنده‌ی سامانه‌ی طراحی (نمایه نمی‌شود)؛ توضیحات در `docs/design-system.md` |
| `/login`, `/register` | ورود و ثبت‌نام (با انتخاب نقش) |
| `/student/*` | پنل دانشجو: داشبورد، دوره‌ها، برنامه‌ی کلاس‌ها، تکالیف |
| `/teacher/*` | پنل استاد: داشبورد، کلاس‌ها، زبان‌آموزان |
| `/admin/*` | پنل مدیریت: نمای کلی، کاربران، دوره‌ها |

## نکات

- داده‌ها فعلاً نمونه هستند (`lib/data.ts`) و ورود/ثبت‌نام فقط کاربر را به پنل نقش انتخاب‌شده می‌برد؛ برای استفاده‌ی واقعی باید بک‌اند و احراز هویت متصل شود.
- رنگ‌های برند در `tailwind.config.ts` (پالت `brand`) و کلاس‌های مشترک در `app/globals.css` تعریف شده‌اند.
- تصاویر افراد از پروژه‌ی [Tail-Kit](https://github.com/Charlie85270/tail-kit) (MIT) گرفته شده‌اند.
- علامت‌گذاری دست‌کشیده (`components/ui/Highlighter.tsx`) و انیمیشن تغییر تم از [Magic UI](https://magicui.design) (MIT) اقتباس شده‌اند.
